# LOSTORY 제품 기획

**상태:** 2026-08-23 팀 합의 반영
**실행 기준:** [MVP_IMPLEMENTATION_PLAN.md](./MVP_IMPLEMENTATION_PLAN.md)와 [IMPLEMENTATION_PLAN.md](./IMPLEMENTATION_PLAN.md)

## 1. 제품 정의

LOSTORY는 습득자가 가까운 분실물 센터를 선택해 물건을 인계하도록 돕고, 신고자의 기억 장소 핀과 등록된 습득물을 비교해 후보를 제시하는 연결 서비스다. 공식 유실물 체계를 대체하거나 소유권을 자동 판정하지 않는다.

| 사용자 | P0 가치 | P1 가치 |
|---|---|---|
| 습득자 | 사진부터 빠르게 등록하고 가까운 센터로 이동·인계를 기록 | 센터 수락·반환을 통해 보상 근거를 얻음 |
| 신고자 | 장소 핀 주변 센터 안내와 점수 기반 Top-5 후보 | 포인트로 제한 상세을 열고 센터에 문의 |
| 센터 담당자 | 없음 | 대시보드에서 인계 수락·보관·반환 관리 |
| ADMIN | 센터 디렉터리·운영 정책 관리 | 파트너 승인·대시보드 계정 활성화 관리 |

## 2. P0 제품 범위

### 2.1 습득물 등록

습득자는 다음 순서로 등록한다.

1. 사진을 올리면 서비스는 `DRAFT` 습득물을 만들고 Vision 추출을 시작한다.
2. 습득 장소·시각·분류를 입력한다.
3. AI가 제안한 공개 특징을 수정하거나 확정한다.
4. 현장 보관, 별도 안전 장소 보관, 가까운 센터 인계 중 하나를 선택한다.
5. 센터 인계 선택 시 NAVER 지도 앱으로 길 안내를 열고, 사용자가 별도로 인계를 확정한다.

사용자 인계 확정은 센터 확인 전의 진술이다. 서비스는 확정한 서버 시각을 인계 시각으로 기록하지만, P1 수락 전까지 사실을 보증하지 않는다.

### 2.2 센터 안내

- 습득물 인계 대상은 습득 장소 1 km 안의 활성 센터를 거리순 최대 10개로 제한한다.
- 분실 신고는 핀 간 간격을 반영한 신고별 동적 반경을 사용한다.
- 신고 생성·수정 때 계산한 센터 안내는 스냅샷으로 저장해 이후 신고 조회에도 제공한다.

### 2.3 후보

- 모든 `ACTIVE`·미만료 습득물이 후보 풀이다. 센터 파트너십이나 물리 보관 여부는 P0 후보 자격 조건이 아니다.
- 후보는 위치 0.35, 시간 0.20, 분류 0.20, 색상 0.15, 공개 설명 0.10 가중합으로 최대 5개를 만든다.
- Vision 실패나 미확정 특징의 해당 점수는 0이다. 남은 가중치를 재정규화하지 않는다.
- P0은 후보 ID·순위·점수만 제공한다. 정확한 위치, 보관 설명, 습득자 신원, 원본 사진, AI 원문은 제공하지 않는다.
- 신고자는 자신의 신고를 닫을 수 있지만 P0에서 FoundItem을 반환 처리할 수 없다.

## 3. P1 파트너 센터와 포인트

### 3.1 파트너 대시보드

P1에서만 기존 디렉터리 센터를 파트너 센터로 연결한다. ADMIN은 오프라인 검토를 마친 센터에 대해 새 관리 이메일로 `PENDING` 계정을 만들고, 승인 뒤 24시간·1회 사용 비밀번호 설정 링크를 별도 채널로 전달한다. 기존 일반 계정은 연결하지 않는다.

활성 센터에는 대시보드 전용 관리 계정이 하나만 있다. 담당자는 자기 센터로 사용자가 인계를 확정한 항목을 보고, 실물이 있을 때만 수락한다. 수락 뒤 보관·비공개 특징·반환을 관리한다.

### 3.2 후보 상세과 포인트

P1은 신고당 한 번의 포인트 차감으로 후보 상세을 보여 준다. 새로고침이나 재시도로 다시 차감하지 않는다.

상세에는 제한 썸네일, 분류, 대략적 발견일, 사용자 확정 공개 특징을 포함한다. 정확한 위치·보관 설명·습득자 식별자는 여전히 제공하지 않는다. 사용자 인계 확정 또는 센터 확인된 항목만 센터 상태와 연락처를 제공한다.

초기 정책은 가입 10포인트, 후보 상세 1포인트, 센터 확인 반환 보상 5포인트다. 값은 운영 설정으로 관리한다. 실제 결제와 현물 교환은 이후 릴리스다.

## 4. 신뢰·개인정보 원칙

- 포인트 결제와 후보 점수는 소유권 증명이 아니다.
- 외부 Vision 처리 사실은 서비스 약관에 고지한다. 제공사의 학습 미사용·보존·처리 지역·비용은 출시 전 확정한다.
- `DRAFT`와 해당 이미지는 24시간 뒤 제거한다. `EXPIRED`·`RETURNED` 이미지의 Object Storage 원본·썸네일은 30일 뒤 제거한다.
- 비공개 특징, 정확한 위치, 원본 이미지, 토큰·비밀번호·스토리지 키를 응답과 감사 로그에서 제외한다.

## 5. 이후 범위

- 실제 결제 충전·현물 교환·환불
- 비센터 보관 항목의 안전한 회수·연락 중계
- 다중 담당자, 센터 자가 신청, 이메일 자동 발송
- 알림 outbox, 위험 신호, 중복 감지, 학습 기반 순위
